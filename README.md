# ربات تاریخگان (Tarikhi Bot)

راهنمای گام‌به‌گام راه‌اندازی — کاملاً رایگان، بدون نیاز به سرور شخصی.

## این ربات چیکار می‌کنه؟

- تاریخچه‌ی ۴ کانال تاریخی (`World5History`، `IranAncient`، `AsrTarikh`، `ancientir`) رو از ابتدا
  تا یک سال پیش می‌گرده (نه پست‌های جدید)، هر بار حداکثر ۱۰ پست، حداکثر ۲ بار در روز.
- پست‌های خوب رو بر اساس بازدید/فوروارد و دسته‌بندی محتوا امتیازدهی می‌کنه.
- هر روز ساعت‌های ۱۰، ۱۳، ۱۶، ۱۹ رو با محتوای مناسب پر می‌کنه (ساعت ۲۲ دست‌نخورده می‌مونه، چون
  خودت پست‌های کتاب‌محورت رو اونجا می‌ذاری).
- ساعت ۱۶: یکی‌درمیون «سخن بزرگان» / «تصاویر ایران قدیم».
- ساعت ۱۹: یک پست حکایت/داستان/شعر + ۲ کتاب فورواردی‌ای که برات پردازش کرده.
- اگه کتابی برای بات بفرستی، خودکار اسمش رو عوض می‌کنه، کپشنش رو طبق فرمت مشخص‌شده ویرایش
  می‌کنه، و برای نوبت بعدیِ ساعت ۱۹ زمان‌بندی می‌کنه.
- اگه یک پست زمان‌بندی‌شده رو دستی حذف کنی، خودکار جایگزینش می‌کنه.

## پیش‌نیازها

- یک اکانت گیت‌هاب (رایگان)
- یک اکانت تلگرام (همونی که ادمین کانال `@Tarikhgan` هست)
- پایتون روی سیستم شخصی (فقط برای یک قدم اولیه، قدم ۳)

---

## قدم ۱: ساخت ریپازیتوری

1. توی github.com یک ریپازیتوری جدید بساز (پیشنهاد: نام `tarikhi-bot`، حالت **Private**).
2. تمام فایل‌های این پروژه رو توش آپلود کن (یا با گیت push کن).

## قدم ۲: گرفتن api_id و api_hash

1. برو به [my.telegram.org](https://my.telegram.org) و با شماره تلفنت وارد شو.
2. برو به «API development tools» و یک اپلیکیشن جدید بساز (اسم و توضیحات دلخواه).
3. `api_id` و `api_hash` رو یادداشت کن.

## قدم ۳: ساخت session string (فقط یک‌بار، روی سیستم خودت)

این قدم باید **روی سیستم شخصی خودت** انجام بشه، نه روی گیت‌هاب، چون نیاز به وارد کردن کد
تأیید تلگرام داره.

```bash
pip install telethon
python get_session.py
```

ازت `api_id` و `api_hash` (از قدم ۲) رو می‌پرسه، بعد شماره تلفن و کد تأییدی که تلگرام برات
می‌فرسته. در انتها یک رشته‌ی طولانی (`session string`) چاپ می‌شه — این رو جایی امن کپی کن.
همچنین آیدی عددی خودت رو هم نشون می‌ده (برای قدم ۵ لازمه).

⚠️ **این رشته معادل رمز عبور اکانت تلگرامته — هرگز جایی جز GitHub Secrets ذخیره‌ش نکن.**

## قدم ۴: ساخت بات (برای دریافت کتاب‌ها)

1. توی تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. `/newbot` بزن و اسم/یوزرنیم دلخواه انتخاب کن.
3. توکنی که می‌ده رو یادداشت کن.
4. یک‌بار به باتِ تازه‌ساخته‌ت پیام `/start` بده (تا بتونه بعداً پیام‌هاتو ببینه).

## قدم ۵: اکانت اصلی رو ادمین کانال کن

اکانت تلگرامی که توی قدم ۳ باهاش وارد شدی (نه بات، بلکه خودت) باید **ادمین کانال `@Tarikhgan`**
باشه، چون این اکانت پیام‌ها رو زمان‌بندی می‌کنه (بات معمولی نمی‌تونه پیام زمان‌بندی‌شده بسازه).

## قدم ۶: تنظیم Secrets در گیت‌هاب

توی ریپازیتوری برو به: **Settings → Secrets and variables → Actions → New repository secret**
و این‌ها رو یکی‌یکی اضافه کن:

| نام Secret            | مقدار                                                |
|------------------------|-------------------------------------------------------|
| `TG_API_ID`            | از قدم ۲                                              |
| `TG_API_HASH`          | از قدم ۲                                              |
| `TG_SESSION_STRING`    | از قدم ۳                                              |
| `TG_BOT_TOKEN`         | از قدم ۴                                              |
| `TG_OWNER_USER_ID`     | آیدی عددی خودت (از خروجی قدم ۳)                       |
| `TG_TARGET_CHANNEL`    | `@Tarikhgan`                                          |

## قدم ۷: فعال‌کردن اجرای خودکار

فایل `.github/workflows/bot.yml` از قبل توی پروژه هست و طبق زمان‌بندی زیر اجرا می‌شه:
- هر ۶ ساعت: چک‌کردن کتاب‌های جدید + پرکردن/به‌روزرسانی اسلات‌ها
- ۲ بار در روز: گشتن تاریخچه‌ی کانال‌ها

برای تست فوری، بدون منتظرِ زمان‌بندی موندن: توی ریپو برو به تب **Actions → Tarikhgan Bot →
Run workflow** و دستی اجراش کن.

## قدم ۸: بررسی نتیجه

- توی تب **Actions** می‌تونی ببینی هر اجرا موفق بوده یا خطا داده (روی لاگ‌ها کلیک کن).
- توی کانال `@Tarikhgan`، بخش «پیام‌های زمان‌بندی‌شده» رو چک کن — باید کم‌کم پست‌های آماده
  رو اونجا ببینی.
- برای فرستادن کتاب: کافیه فایل PDF کتاب رو با کپشن مناسب (طبق فرمتی که قبلاً توضیح داده شد)
  برای باتی که توی قدم ۴ ساختی بفرستی.

## ساختار فایل‌ها

```
config.py          تمام تنظیمات (کانال‌ها، ساعت‌ها، کلیدواژه‌ها)
text_utils.py       پاک‌سازی متن، پردازش کپشن کتاب، تشخیص جلد
telegram_client.py  اتصال به تلگرام + خواندن/نوشتن فایل‌های وضعیت
scan_history.py     گشتن تاریخچه‌ی کانال‌ها و ساخت صف پست
process_books.py    پردازش کتاب‌های فورواردشده
schedule_posts.py   پرکردن اسلات‌ها + جایگزینی پست‌های حذف‌شده
get_session.py      اسکریپت یک‌بارمصرف برای ساخت session string
state/              فایل‌های وضعیت (بین اجراها حفظ می‌شن، توسط Actions کامیت می‌شن)
```

## نکات مهم

- کلیدواژه‌های دسته‌بندی توی `config.py` (بخش `CATEGORY_KEYWORDS`) هستن — با دیدن نتایج واقعی،
  می‌شه به‌مرور کامل‌ترشون کرد.
- اگه بعد از مدتی دیدی صف پست‌ها (`post_queue.json`) یا صف کتاب‌ها (`book_queue.json`) خالی
  می‌مونه، یعنی باید صبر کنی تا `scan_history.py` بیشتر از تاریخچه رو بگرده، یا کتاب بیشتری
  بفرستی.
- هزینه‌ی این پروژه صفره — نه برای اجرا (GitHub Actions رایگانه)، نه برای هوش مصنوعی (از هیچ
  API پولی استفاده نمی‌کنه، فقط قوانین و کلیدواژه).
